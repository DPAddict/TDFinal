## Auto OverLapper

<img SRC="Assets/Maya Widget Tool.png" width=300>

A tool that can help with overlapping in animation when it comes too fingers and or hair

---

## How To Install

<img SRC="Assets/Instal.png" width=300>

 - Drag install file into Maya workspace
 - Then find it on your Maya shelf and click it
 - Select either a controller for a strand of hair, or a finger and make it your base
 - Then key the first frame and then another frame at a different rotation
 - Then select the controllers you wish to follow the base and hit pick chain
 - Select the amount of offset you wish to add 
 - Then click apply
 - Now watch as it adds a cool overlap!




----

## Known Bugs 


- If the rotation is to much it will phase into the mesh
- It will overlap every rotation so it the fingers are rotated in ways that are not normal it will follow that
